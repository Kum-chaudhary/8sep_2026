Function : Function is a block of code 
         that code we can use again and again.

         Function mainly use to reduce code.

         function provide reusability.

         using of function we can save our time.

    in python there are 2 types of function :
        1) Built-in Function
        2) user define function

----------------------------------------------------------------------

1) Built-in Function :
     which is predefined by python 
      e.g., print(), input(), len()..,

2) user - define Function:
     user create function as per requirement.

     there are 2 steps to create user define function :

       steps 1 : function defination 

       syntax:   def <funname>():
                  block of code

       steps 2:   function calling

        syntax :   <funname>()        

---------------------------------------------------------
Function Categories :

there are 4 types of function Categories :

1) function without parameter and function without return type.
2) function without parameter and function with return type.
3) function with parameter and function without return type.
4) function with parameter and function with return type.
