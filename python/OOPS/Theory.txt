Magic Method :
--------------
 in python magic method are special methods 
which have prefix and postfix __(double underscore).

in simple language we can say that special method and in python 
we call it as a dunder method.

dunder methods means double underscore methods.

1) ___init__():
  which is mainly use as a constructor.

  whenever we create object of class it invoke automatically.

  main meaning of ___init__ means initilization 
  of object.

2) __str__():

 which is used to represent any class object as a string format.

 syntax:
     
     def __str__(self):
     return "Message"

3) __add__():
  when we want to perform operations between multiple objects property.

  when we call + (addition operations) this magic method invoke
  automatically.

4) __len__():
  whenever we want to extract length of object we can use len 
  magic methods.  

5) __getitem__():
  getitem which is used to acess properties of dictionary
  using of index wise.
