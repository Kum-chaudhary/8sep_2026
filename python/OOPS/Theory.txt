4) Inheritence :
    Inheritence is a most powerfull concept of python.

    Inheritence provide reausability.

    using of Inheritence we can reduce our code.
    and save developed time.

    there are mainly 5 types of Inheritence :

  i) single level Inheritence :

     one class derived properties of another class its called 
     single level Inheritence.

        class Parent 
             |
             V 
        child class       

    ii) Multi level Inheritence :
     
     one class derived properties from another class and extended
     level of single level Inheritence we can say multi level Inheritence.

      syntax : 

          class a
            |
            V 
          class b 
            |
            V 
          class c 

    Class A :  (parent class , or super class, base class) 
    class B :  (child class , or sub class , Derived class)


    iii) Multiple Inheritence :

      one child class can have more than 1 parent class 

         A      B 
         |      |
         --------
             C
