collection is a group of elements which is access multiple data types.

there are mainly 4 types of collection :

       1) list
       2)tuple
       3)set
       4)dictionary

1) List : list is a most powerful data type of collection which
 is represent by [] braces.

 list is a mutable data type.

 we can change it value after creation.

 e.g., example = []  

----------------------------------------------------------------------------------------------------------
1) remove(): when we want to remove specific element from the existing list

  syntax: 
   list.remove(element)

2)pop():
       it will remove all last element from the list  
       by default remove all last element from the list.

       syntax: list.pop(element)

  pop(index)  : when we want to remove element from specific index position   

     syntax: list.pop(index)   

3)clear():
   when we want to remove all elements from the list 

    syntax: 
      list.clear(index)

4) del()
 del is a keyword which is use to delete list variable from the memory.                
  syntax :
    list.del()
